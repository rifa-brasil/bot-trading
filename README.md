# Investment Telegram Bot

Bot de Telegram para gestionar una plataforma de inversión.

## Tecnologías

- Python
- python-telegram-bot
- SQLite
- Render
- GitHub

## Funciones iniciales

- Registro de usuarios
- Menú principal
- Perfil de usuario
- Panel administrativo
- Base de datos SQLite

## Configuración

Crear las variables de entorno:

BOT_TOKEN=TOKEN_DEL_BOT
ADMIN_ID=ID_DEL_ADMINISTRADOR

## Ejecutar

```bash
pip install -r requirements.txt
python bot.py
